# La Roche Cafe — القائمة الرقمية

قائمة رقمية لـ **لاروشيه كافيه** (مرسين / السولي) — صفحة واحدة، تركي/عربي، تُفتح بمسح QR من الطاولة.

**الموقع:** https://otillion.github.io/laroche-menu/
**لوحة التحكم:** https://otillion.github.io/laroche-menu/admin/

## المزايا

- 109 صنف في 12 قسم، بالصور والأسعار
- تركي افتراضياً، وعربي بضغطة واحدة (RTL/LTR تلقائي)
- كل الأقسام ظاهرة بدون تمرير جانبي
- بحث فوري، وضغط أي صنف يفتح صورته كبيرة
- مقطع فيديو خلف الشعار، يتوقف خارج الشاشة ويُلغى في وضع توفير البيانات
- وضع ليلي تلقائي حسب إعداد الجهاز

## لوحة التحكم

`/admin/` تتيح لصاحب الكافيه تغيير الأسعار والأسماء والصور، وإضافة أو حذف المنتجات
والأقسام، ثم الحفظ مباشرة — بدون أي تعامل مع الكود.

- **كلمة المرور** محفوظة في `menu.json` كبصمة PBKDF2-SHA256 (١٢٠ ألف دورة) مع ملح عشوائي،
  ويمكن تغييرها من داخل اللوحة.
- **الحفظ** يتم عبر GitHub Contents API باستخدام توكن يُدخله المالك مرة واحدة ويُحفظ في
  متصفحه فقط (`localStorage`). التوكن ليس جزءاً من المستودع ولا يُرفع إليه إطلاقاً —
  المستودع عام، وأي توكن يُرفع إليه تُلغيه GitHub تلقائياً.
- بدون توكن تبقى اللوحة صالحة للتعديل، لكن زر الحفظ يُنزّل `menu.json` لرفعه يدوياً.
- الصور الجديدة تُصغَّر داخل المتصفح إلى 800×600 WebP وتُرفع إلى مجلد `img/`.

## البيانات

كل المحتوى في `menu.json`:

```json
{
  "v": 1,
  "auth": { "salt": "…", "iter": 120000, "hash": "…" },
  "cats": [
    { "id": "ice", "ar": "بوظة", "tr": "Dondurma", "icon": "ice",
      "items": [
        { "ar": "شوكلامو", "tr": "Şokolamo", "p": 250,
          "img": "2023/11/DSC08279.jpg", "s": ["-300x300", "-768x768"] }
      ] }
  ]
}
```

- `p: 0` يعرض «حسب الطلب» / «Fiyat sorunuz»
- `img` إمّا ملف داخل المستودع (`img/…`)، أو رابط كامل، أو مسار داخل مجلد الصور الأصلي
  — وعندها يحمل `s` لواحق المقاسات المصغّرة المستخدمة في `srcset`
- `icon` أحد: `ice, redbull, salad, smoothie, juice, cold, cocktail, shake, hot, canned, waffle, crepe`

`index.html` يقرأ `menu.json` عند الفتح، ويحتفظ بنسخة احتياطية من البيانات داخله،
فإذا تعذّر تحميل الملف أو كان تالفاً تبقى القائمة تعمل.
