# Laroche Cafe — Digital Menu

قائمة رقمية لـ **لاروشيه كافيه** (مرسين / السولي) — صفحة واحدة، عربي/تركي، تعمل بمسح QR من الطاولة.

**الرابط المباشر:** https://otillion.github.io/laroche-menu/

## المزايا

- 109 صنف في 12 قسم، مع الصور والأسعار
- عربي / تركي بضغطة واحدة (RTL/LTR تلقائي)
- بحث فوري + فلترة بالأقسام
- ضغط على أي صنف يفتح الصورة كبيرة
- وضع ليلي تلقائي حسب إعداد الجهاز
- ألوان الهوية: أخضر / أبيض / أسود، مع شعار المقهى كـ SVG

## التعديل

كل البيانات في مصفوفة `MENU` داخل `index.html`:

```js
["الاسم بالعربي", "Türkçe adı", السعر, "مسار-الصورة", "-مقاس-صغير", "-مقاس-كبير"]
```

- السعر `0` يعرض "حسب الطلب"
- الصور تُحمّل من owlmenu.net بمقاسات مناسبة عبر `srcset`

## البنية

ملف واحد `index.html` — لا بناء ولا اعتماديات.
